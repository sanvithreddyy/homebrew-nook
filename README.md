# Homebrew tap for Nook

```
brew install --cask sanvithreddyy/nook/nook
```

[Nook](https://github.com/sanvithreddyy/nook) turns your Mac's notch into a live island. This tap installs the release DMG from that repository; `brew upgrade` picks up new versions. Use the full name above: a plain `brew install nook` installs a different app.
